HoverNet community track library
================================

This pack holds about a thousand tracks made by the HoverRace community over the
years, installed exactly as they were published: no track has been edited.

They appear in HoverNet's track selectors (local race setup and online host
dialog) below the bundled official tracks, with a search box for finding one.
Tracks marked "free play" have no finish line, so no laps can be completed
(battle, tag and sports arenas).

Installing
  * Linux:   scripts/install-community-tracks.sh PACK.zip
             (or install the hovernet-community-tracks .deb)
  * Windows: powershell -File scripts\install-community-tracks.ps1 -Source PACK.zip
  * Anywhere: unzip the CommunityTracks folder into NetTarget\ beside the game.

Online races
  Everyone in a race needs the same track, so players who join a community track
  must have this pack installed. The race server must also list the track in its
  CommunityTracks.tsv.

Licence
